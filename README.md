# Replication Package — Cross-Market ESG / Total-Accrual Study

Anonymous replication repository accompanying the manuscript submitted to
*[Anonymous Journal]*. Author information is withheld for double-anonymous
peer review.

This repository reconstructs the United States portion of a Korea–United States
comparison of single-source ESG proxies, using only free, public data so that
the analysis is fully reproducible without any paid subscription.

## What this code does

It builds a firm-year accounting panel from public filings, forms
total-accrual–sorted portfolios, and estimates their risk-adjusted alphas under
the CAPM, the Fama–French three-factor model, and the Carhart four-factor
model. The governance proxy (total accruals) is the focus; the environmental
and social proxies are discussed in the manuscript.

## Data sources (all free, no paid subscription)

- **SEC EDGAR XBRL "frames" API** — firm-year accounting items (no API key).
- **yfinance** — monthly adjusted equity prices.
- **Kenneth French Data Library** — market, size, value, and momentum factors.

## Variable definitions (mapped to the manuscript equations)

- Total accrual: `TACC = (NetIncomeLoss - NetCashProvidedByUsedInOperatingActivities) / Assets(t-1)`
- Gross profit over assets: `GPOA = (Revenues - CostOfRevenue) / Assets(t-1)`
- Portfolio alphas: CAPM / FF3 / Carhart, low-minus-high total-accrual hedge.

## How to run

Run the notebooks in order: `01 -> 02 -> 03 -> 04`.
Notebooks `03` and `04` are provided already executed; `01` and `02` perform
live downloads and can be re-run to refresh the panel.

Before running `01`, set a descriptive User-Agent string in the EDGAR request
header (the SEC requires one; any descriptive string with a contact works). The
committed value is an anonymous placeholder.

## Important limitations

- The free price feed is **not survivorship-bias-free** and is not
  point-in-time correct; delisted names may be missing, which can inflate
  long-short returns. Because this bias operates in both markets, it is less
  likely to drive the cross-market comparison that is the paper's focus, and
  the accounting-based regressions (notebook `03`, part A) are far less exposed
  to it. The manuscript places primary weight on those regressions and treats
  the portfolio alphas as supporting evidence.
- The price universe is **capped** (deterministic, alphabetical) for runtime
  feasibility; remove or raise the cap in notebook `02` to use the full
  universe.
